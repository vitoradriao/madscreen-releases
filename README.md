# madscreen

Instaladores públicos do madscreen para Windows x64. Este repositório não contém o código-fonte do aplicativo.

Baixe o instalador na [release mais recente](https://github.com/vitoradriao/madscreen-releases/releases/latest). O mesmo aplicativo permite compartilhar a tela e assistir.

Requisitos: Windows com WebView2; para transmitir, GPU NVIDIA compatível com NVENC. O instalador inclui o engine e instala WebView2 se necessário.

Abra um convite recebido no navegador e escolha **Já tenho o app** após instalar. A entrada no servidor/canal depende da versão correspondente do serviço de sinalização.
